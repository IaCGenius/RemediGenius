# Remediation preparation through skills

2026-10-14. This change extends the existing `ce-aws-security` skill; no application
code, model transport, cloud write capability or new remediation agent was added.

## Operator experience

Ask about a real finding and say "help me fix it." With no format preference,
Hermes should obtain relevant evidence and lead with a concise AWS CLI fix when
the scope and prerequisites support one. It then offers Terraform or CloudFormation.
Choose either, or request both, in the same conversation. Relevant supplied source
can support a specific proposed edit; an unseen repository cannot.

Do not compress a multi-step change into a misleading one-liner. Missing ownership,
destination or recording-scope choices should produce useful prechecks and a short
outline, followed by the precise question needed to complete the change. Explicit
preferences take precedence; all three formats are not generated by default.

After execution by the operator, ask for reassessment. CE collects fresh supported
evidence and distinguishes verified, partially verified, not corrected and unable
to verify. A proposed change and an AI critique are not execution or validation.
