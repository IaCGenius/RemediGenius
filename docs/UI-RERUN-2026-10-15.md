normalized findings shape; reread the exact saved finding before follow-up review;
separate incident investigation from optional hardening; distinguish unknown
destinations from absent configuration; state the precise scope of MFA Delete;
use explicit CloudFormation retention policies and accurate import behavior;
inspect case comments before repeating a correction; request only redacted,
relevant source context. The runtime owns the single review-status heading.

step; no customer-cloud remediation was performed.
