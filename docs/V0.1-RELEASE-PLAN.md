# v0.1.0 release scope

**AWS us-east-1, Qwen 3.8 Max, native Hermes, one ce-desk profile.** Bedrock is
explicitly deferred. This release does not claim every AWS service, region or model.

| Area | Result |
|---|---|
| Native source layout | profiles/ce and deploy/aws-native; runtime resource/profile identities unchanged |
| Legacy removal | Console, broker, builder/prototype deployments and their tests archived outside CE |
| Local/source tests | Windows and Linux checks passed; see [release validation](RELEASE-VALIDATION.md) |
| Qwen | Renamed package exercised with real scoped AWS reads and critic context |
| Retained-installation upgrade | Tested with backup and preservation checks |
| Packaging | Python metadata/wheel 0.1.0; source, native package and checksums accompany the GitHub release |
| Public support | Issues, Discussions and GitHub private vulnerability reporting enabled |
| Verification | Local checks completed; no successful GitHub Actions run claimed |
