This supports an owner-reviewed, single-operator friend preview. Remaining native
Hermes UI rough edges include the default route shown by Profiles, inconsistent
skill counts across screens, and the upstream copy-response behavior. The default
route now uses the same Qwen model and CE boundary; it is not an unrestricted
second provider. These UI observations are not hidden behind a release-ready label.

No autonomous remediation, universal repository OAuth, automatic account enrollment,
Security Lake record queries, Azure/GCP collectors, automatic decision reopening,
alert delivery or cross-region case replication is claimed. CLI/Terraform/
CloudFormation proposals use Hermes skills; they are not validated execution adapters.
Scheduled collection is now CE scope. Its bounded checks are not a complete AWS security scan.
