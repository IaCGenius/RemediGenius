# v0.1 candidate validation receipt

Date: 2026-10-12. This receipt records local validation, not a production certification.

## Verified locally

- Fresh Python 3.12 virtual environment installation from the checkout with the
  `aws,mcp,test` extras. `pip check` reports no broken requirements.
- Local package builds as a wheel with its static UI, capability manifest, rule
  code, provenance and licence material.
- 50 core/API/adapter, community privacy/IAM and kiosk CLI tests pass. MCP is
  exercised both in memory and over a real stdio subprocess.
- All 38 preserved deterministic rule cases pass. The legacy result-view checks
  pass with the corrected NOT_OBSERVED semantics.
- All 30 existing Lambda kiosk tests pass. No kiosk resources were provisioned.
- Edge/Playwright browser exercise: sample, investigation, proposal, comparison,
  knowledge approval and MCP configuration. Source markup stays text. No page
  errors; mobile layout checked for horizontal overflow. Screenshots are local
  test output, not customer evidence.

Tests specifically cover incomplete/missing/stale data, scope and engine mismatch,
changed worst-rule classification, fixed severity despite malicious AI text,
cross-account ASFF rejection, hash-bound approval, record tampering, cross-origin
HTTP requests, collector budget exhaustion and read-only session policy.
