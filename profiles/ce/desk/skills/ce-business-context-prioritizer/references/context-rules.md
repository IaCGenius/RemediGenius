# Applying organizational context

Match exact resource identifiers with account/region, or explicit tag selectors whose values are observed. Cite matched fields and selected source metadata. Names alone do not prove purpose.
Explain source -> applicability -> priority effect -> unknowns. Exceptions do not automatically lower priority: consider stated scope, prerequisites, validity if supplied, conflicts and residual risk. Preserve native severity and findings. A documented category variation is distinct from accepting a policy deviation; do not invent expiry or approval requirements absent from the policy. Unresolved conflict stays explicit; import time is not precedence.
