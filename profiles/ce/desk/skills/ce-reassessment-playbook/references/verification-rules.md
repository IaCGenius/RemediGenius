# Verification classification rules

- **Verified** — Fresh receipt shows the intended field value (e.g., BlockPublicPolicy=true) and the prior receipt showed the opposite.
- **Partially verified** — Some but not all intended fields changed.
- **Not corrected** — Fresh receipt shows the same undesired value.
- **Unable to verify** — Fresh read failed, timed out, or covered a different resource.

Always cite both receipt IDs and timestamps.
