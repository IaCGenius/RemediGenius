# Scoped reassessment

Agree the intended condition and resource/account/region first. Use a fresh receipt and compare equivalent fields/scopes; pagination, permission gaps or missing evidence cannot count as a fix.
- Verified for the stated condition: fresh evidence establishes that condition with sufficient scope. A changed value alone is insufficient; the old value need not be its Boolean opposite.
- Partially verified: only some required conditions are evidenced.
- Not corrected: fresh sufficient evidence still contradicts the intended condition.
- Unable to verify: read failure, scope mismatch or insufficient evidence.

Cite both receipt IDs/times when available. If no prior receipt exists, describe current condition only; do not claim change attribution. Snapshot CHANGED/UNCHANGED is deterministic; remediation effectiveness is a separate assessment. Do not close a case automatically or infer a fix from a disappeared finding.
